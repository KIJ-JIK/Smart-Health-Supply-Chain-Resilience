# District & State Governance Portal

**Component: Member 1 (`apps/governance-portal`)**

---

## Overview
The Governance Portal provides District Chief Medical Officers (CMOs) and State Health Secretaries with top-level operational visibility, AI-driven stock redistribution recommendations, GIS heatmaps, and emergency crisis protocols.

### Key Capabilities
- Multi-facility bed, oxygen, and medicine status overview.
- AI Supply Redistribution Approval workflow (MILP optimization).
- Crisis Mode trigger and district-wide surge reallocations.
- Direct connectivity to Central Backend (`http://localhost:8000`).

### Run Locally
```bash
npm install
npm run dev
```
Port: `3000`
